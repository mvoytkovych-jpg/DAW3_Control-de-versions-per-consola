A continuación tenéis que hacer A TRAVÉS DE LA TERMINAL DE GIT BASH POR COMANDOS:

# Crear proyecto y primer commit
- Crear un repositorio vacío en GitHub.
- Invitar a colaboradores.
- Clonarlo en local.
- Crear un archivo Java simple HolaGit.java con un mensaje por pantalla.
- Hacer commit y subirlo al repositorio remoto.

# Crear ramas y modificar el proyecto
Cada miembro del grupo debe:

- Clonar el respositorio en local.
- Crear una rama personal donde realizará los cambios.
- Modificar el archivo Java para añadir su propio mensaje.
- Hacer commit y subir su rama al remoto.

# Fusionar cambios al main
- Crear una fusión (merge) de cada rama a la rama principal del proyecto.
- Comprobar que todos los cambios se mantienen y el programa funciona.

# Resolver un conflicto de merge
- Dos miembros del grupo deben modificar la misma línea del archivo.
- Al fusionar, aparecerá un conflicto.
- Deberéis resolverlo correctamente y dejar el repositorio funcional.

# Sincronización final
- Todos los miembros deben actualizar su repositorio local con los cambios finales del remoto.

# Material a entregar
En la entrega final debéis incluir un pdf con:
Enlace al repositorio en GitHub
Capturas de pantalla de:
- Consola usando comandos de Git
- Trabajo con ramas
- Fusión entre ramas
- Conflicto y su resolución
- Historial de commits

Código Java ejecutable con los mensajes del equipo
